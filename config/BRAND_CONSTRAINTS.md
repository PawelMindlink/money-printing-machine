# Iiyama Brand Constraints

> **Purpose:** This document defines immutable rules and stylistic guidance for all creative assets.
> **Source:** Onboarding transcript + VOC Harvest data analysis

---

## 🔴 HARD CONSTRAINTS (The Red Lines)

These are **IMMUTABLE VETOES**. Any creative that violates these must be rejected.

### 1. Product Limitations

| Constraint | Source | Creative Impact |
| :--- | :--- | :--- |
| **OSD controls on rear** | Harvest (confirmed across all series) | Never claim "intuitive controls" |
| **Yellow tint / 6500K failure** | Harvest (Reddit systematic issue) | Never claim "factory calibrated" for non-ProArt |
| **Panel lottery (uniformity)** | Harvest (higher variance than Dell) | Never claim "zero defects" or "perfect quality control" |
| **USB hub bandwidth at 4K** | Harvest (technical limitation) | Qualify USB hub claims with resolution |
| **Pivot stand height issues** | Harvest (recurring across models) | Don't oversell ergonomics on budget models |

### 2. Service Limitations

| Constraint | Source | Creative Impact |
| :--- | :--- | :--- |
| **Global support slower** | Harvest (vs Dell/Samsung) | Focus on product value, not support speed |
| **iiWare Android limitations** | Harvest (sideloading issues) | Don't claim "full Android" for signage |
| **WiFi reconnection on boot** | Harvest (TE series) | Qualify "always connected" claims |
| **No Polish UI on signage** | Harvest (Ceneo complaints) | Be cautious with "local support" messaging |

### 3. Messaging Vetoes

| Veto | Reason |
| :--- | :--- |
| ❌ "Best in class colors" | Not true vs Dell UltraSharp / ASUS ProArt |
| ❌ "Zero bad pixels guarantee" | Not offered on budget models |
| ❌ "Premium build quality" | Thick bezels and rear buttons contradict this |
| ❌ "HDR gaming ready" | HDR-Ready is marketing term only |

## 🟢 SOFT CONTEXT (Brand Flavor)

These are **STYLISTIC SUGGESTIONS** that inform tone but don't veto content.

### 1. Market Position

- **Primary Value Prop:** "90% of Dell quality at 60% of the price"
- **Sweet Spot:** Budget-conscious professionals who know how to calibrate
- **Risk:** Panel lottery - higher variance than premium brands

### 2. Segment Personas

| Segment | Persona | Tone |
| :--- | :--- | :--- |
| Gaming | Gracz Kompetytywny, Streamer | Energetic, Technical, RGB |
| Office | IT Admin, Remote Worker | Clean, Professional, Productivity |
| ProGraphics | Grafik, Fotograf, Architekt | Precise, Studio, Color-critical |
| Signage | Marketing Manager, AV Integrator | Commercial, Reliable, 24/7 |

### 3. Competitor Anchors

- **Dell UltraSharp:** "Same panel, half the price"
- **Samsung/LG Gaming:** "Pro features without the gamer tax"
- **BenQ PD:** "Creator monitor without the wait"

---

## ⚠️ CONFLICT RESOLUTION RULES

> **When Client Aspiration conflicts with Harvest Data, HARVEST DATA WINS for the selling angle.**

| Client Might Say | Harvest Data Says | Creative Decision |
| :--- | :--- | :--- |
| "We are premium" | "Best budget choice" | Sell on VALUE, not luxury |
| "Our quality is superior" | "Panel lottery exists" | Sell on SPECS, not QC |
| "We have great support" | "Support is slower than Dell" | Don't mention support |
