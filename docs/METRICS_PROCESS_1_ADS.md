# Metric Definitions: Process 1 (Meta Ads Analysis)

**Purpose:** Analyze the efficiency of paid traffic acquisition at the Ad level.
**File:** `Output/[Brand]/[Brand]_Ad_Analysis.csv`

## 1. Source Metrics (Meta Ads)

| Metric | Code Name | Definition |
| :--- | :--- | :--- |
| **Ad Name** | `meta_ad_name` | Name of the creative in Meta Ads Manager. |
| **Amount Spent** | `meta_spend` | Total budget consumed by this ad. |
| **Purchases** | `meta_purchases` | Number of transactions attributed to this ad. |
| **Conversion Value** | `meta_revenue` | Total revenue attributed to this ad (Gross). |
| **ROAS** | `meta_roas` | `meta_revenue / meta_spend`. Return on Ad Spend. |

## 2. Context Metrics (Feed Link)

| Metric | Code Name | Definition |
| :--- | :--- | :--- |
| **Margin** | `base_gross_margin` | Product margin derived from Ad Name or Feed Category. |
| **Price Cluster**| `calc_price_cluster` | Price tier of the promoted product. |

## 3. Financial / Calculated Metrics

| Metric | Code Name | Formula & Logic |
| :--- | :--- | :--- |
| **Net Revenue** | `calc_net_revenue` | `meta_revenue / (1 + vat_rate)` |
| **COGS** | `calc_cogs` | `calc_net_revenue * (1 - base_gross_margin)` |
| **Contribution Profit** | `calc_contribution_profit` | `meta_revenue - meta_spend - calc_cogs`. The actual profit generated by this ad after paying for the product and the ad space. |
| **Break Even ROAS** | `calc_break_even_roas` | `1 / base_gross_margin`. The ROAS needed to make 0 profit. |
| **Scaling ROAS** | `calc_scaling_roas` | `calc_break_even_roas * 1.2`. 20% buffer above break-even. |
| **Bid Cap** | `calc_bid_cap` | `(Product Price / (1+VAT)) * Margin`. Max CPA to break even on one unit. |
| **Cost Cap** | `calc_cost_cap` | `calc_bid_cap * 0.7`. Safe target CPA. |

## 4. Decision Logic (`calc_action`)

* **COPY (PROFIT)**: `calc_contribution_profit > 0`. This ad is making money now.
* **COPY (ROAS)**: `meta_roas >= calc_break_even_roas` (and `meta_spend > 0`). This ad is efficient enough to scale.
* **PAUSE (LOSER)**: `meta_spend > (2 * Bid Cap)` AND `calc_contribution_profit < 0`. Proven failure.
* **TESTING**: Not enough spend to decide.
