# MASTER DATA DICTIONARY (All Sources)

## 1. Source: Product Feed (`feed_`)

*Origin: Google/Meta Merchant Center XML*

| Metric | Definition |
| :--- | :--- |
| `feed_id` | Unique Product ID (SKU). |
| `feed_title` | Product Name. |
| `feed_brand` | Brand Name. |
| `feed_category` | Product Category (taxonomy). |
| `feed_price_str` | Raw price string (e.g., "129.00 PLN"). |
| `feed_price_numeric`| Numeric price parsed from string. |
| `feed_link` | URL to the product page. |

## 2. Source: GA4 Landing Page (`ga4lp_`)

*Origin: Standard Report (Scope: Session). Key: Page Path.*

| Metric | Definition |
| :--- | :--- |
| `ga4lp_sessions` | Total sessions starting on this URL. |
| `ga4lp_users` | Total users engaged. |
| `ga4lp_purchases` | Total transactions attributed to this Landing Page. |
| `ga4lp_revenue` | Total revenue attributed to this Landing Page (Gross). |

## 3. Source: GA4 Items (`ga4item_`)

*Origin: Item Report (Scope: Item). Key: Item ID.*

| Metric | Definition |
| :--- | :--- |
| `ga4item_views` | `Items viewed`. Number of times product details were viewed. |
| `ga4item_purchases` | `Items purchased`. Number of units sold. |
| `ga4item_revenue` | `Item revenue`. Revenue generated by this specific item. |

## 4. Source: Meta Ads (`meta_`)

*Origin: Ads Manager Export. Key: Ad Link.*

| Metric | Definition |
| :--- | :--- |
| `meta_spend` | Amount spent (PLN). |
| `meta_revenue` | Conversion Value (Gross). |
| `meta_purchases` | Number of Purchases. |
| `meta_roas` | Return on Ad Spend (`meta_revenue / meta_spend`). |
| `meta_ad_name` | Name of the Ad. |

## 5. Calculated Metrics (`calc_`)

*Origin: Pipeline Logic (MSC-ALGO v1.0)*

### Financials

| Metric | Formula | Definition |
| :--- | :--- | :--- |
| `base_gross_margin` | *Dynamic Lookup* | Margin rate (0.0 - 1.0). |
| `calc_net_revenue` | `Revenue / (1 + VAT)` | Revenue excluding tax. |
| `calc_gross_profit` | `calc_net_revenue * base_gross_margin` | Gross Profit generated. |
| `calc_contribution_profit` | `(calc_net_revenue * base_gross_margin) - meta_spend` | **CM**. Net profit after paying for product and advertising. |

### Efficiency (Unit Economics)

| Metric | Formula | Definition |
| :--- | :--- | :--- |
| `calc_cr` | `ga4lp_purchases / ga4lp_sessions` | **CR**. Conversion Rate (Transactions per Session). |
| `calc_gpps` | `calc_gross_profit (LP) / ga4lp_sessions` | **GPPS**. Gross Profit Per Session. |
| `calc_gppv` | `calc_gross_profit (Item) / ga4item_views` | **GPPV**. Gross Profit Per View. |

### Thresholds (Dynamic P75)

| Metric | Definition |
| :--- | :--- |
| `threshold_p75_vol_meta` | 75th Percentile of `meta_revenue`. |
| `threshold_p75_eff_meta` | 75th Percentile of `calc_contribution_profit`. |
| `threshold_p75_vol_ga` | 75th Percentile of `ga4lp_sessions`. |
| `threshold_p75_eff_ga` | 75th Percentile of `calc_gpps`. |
| `threshold_p75_vol_item` | 75th Percentile of `ga4item_views`. |
| `threshold_p75_eff_item` | 75th Percentile of `calc_gppv`. |

### Final Classification

| Metric | Value |
| :--- | :--- |
| `calc_priority` | 1-7 (Integer). The MSC-ALGO Priority. |
| `calc_segment` | System Name (e.g., `PROVEN_STAR`, `HIDDEN_GEM`). |
